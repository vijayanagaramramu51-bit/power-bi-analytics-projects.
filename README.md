# Power BI Analytics Projects

A portfolio containing two Power BI projects: Retail Analytics and E-Commerce Analytics.

## Project files

- `Retail_Analytics.pbix` — Retail Analytics report
- `ECommerce_Analytics.pbix` — E-Commerce Analytics report
- `Retail_Case_Study.pdf` and `ECommerce_Case_Study.pdf` — supplied project briefs
- `Retail_Source_*` and `ECommerce_Source_*` — data files for each report

## Open the reports

Open either `.pbix` file in Power BI Desktop. If Power BI asks for source paths when refreshing, choose the corresponding source files in this repository.

## Sharing note

This package includes the supplied project briefs and source data. Publish it publicly only if you are permitted to share those materials. A `.pbix` report can also contain imported data.
